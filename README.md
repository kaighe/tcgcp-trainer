# tcgcp-trainer
> Live site [here](https://tcgcp.kaialbertson.ca/)

This is a training tool for the game ***Taco Cat Goat Cheese Pizza***, which is popular amongst my roommates.

High-res scans were taken of the physical cards and processed with [OpenCV](https://opencv.org/) while [ThreeJS](https://threejs.org/) is used to render them.

**NOTE:** *I am aware that this codebase is ugly, I just wanted to finish it quickly so my friends could use it.*

## Building
```
npm install
npm run build
    or
npm run dev
```
